### Проверка памяти и границы старого Core

Операции `VelantrimCore.remember()` и `forget()` согласуют долговременную запись
с локальным кэшем SSB после успешной операции SQLite. `LegacyMemoryEngine.store`
использует этот же путь; `recall` возвращает список из нуля или одной записи по
точному ключу, а не семантический поиск. Параметр `importance` в старой LTM не
сохраняется.

Проверка: `python -m unittest discover -s tests -v`. Тесты охватывают обновление,
удаление, ошибки записи и повторное открытие базы. Эта согласованность относится
к API одного экземпляра Core: прямые изменения через `ltm`/SQL и изменения из
других процессов не дают автоматической инвалидации чужого SSB. Современный
Crystal остаётся отдельным проектом со своими контрактами.
